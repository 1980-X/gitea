# Gitea SSH enabled on 18622

> Source: local compose change and port check on gpu001
> Collected: 2026-08-19
> Published: 2026-08-19

Git SSH enabled for Gitea stack. Host port 18622 maps to gitea container port 22. Port 22 on host remains system sshd and was not used.

Pre-check: 18622 was free before apply. 18600 remains gitea-nginx HTTP. gitea HTTP 3000 and gitea-db 5432 are not published to host.

Environment: GITEA_SSH_PORT=18622, GITEA**server**DISABLE_SSH=false, GITEA**server**SSH_PORT=18622, GITEA**server**SSH_LISTEN_PORT=22.

app.ini after recreate: DISABLE_SSH=false, SSH_PORT=18622, SSH_LISTEN_PORT=22. ROOT_URL unchanged http://192.168.1.84:18600/.

SSH does not go through nginx. Clone URL form: git@192.168.1.84:18622:owner/repo.git. User must add SSH public key in Gitea settings.

Verification without user key: ssh to port 18622 returns Permission denied publickey which indicates SSH service is listening.
